#  Book Store Management System – SQL Project

##  Project Overview
The Book Store Management System is a SQL-based project developed using MySQL to manage book inventory, customer information, orders, and sales transactions. This project demonstrates practical SQL skills and database management techniques to extract meaningful business insights.

##  Project Objectives
- Manage book inventory and availability.
- Maintain customer and order information.
- Analyze sales performance and revenue.
- Retrieve meaningful insights using SQL queries.
- Understand relationships between database tables.

##  Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

##  SQL Concepts & Functions Used
- DDL and DML Commands
- Primary Key and Foreign Key
- Joins (INNER, LEFT, RIGHT)
- Subqueries and CTEs
- Aggregate Functions (SUM, AVG, COUNT, MIN, MAX)
- GROUP BY and HAVING
- CASE Statements
- Window Functions
- ORDER BY and WHERE

##  Key Analysis Areas
- Book inventory and stock analysis
- Customer purchase analysis
- Sales and revenue analysis
- Order management
- Business insights using SQL queries

##  Project Structure
- `Book_Store.sql` – SQL database creation, table structures, data insertion, and analysis queries.
- `README.md` – Project documentation.
